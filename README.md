This project is part of the Codecademy Python course and focuses on working with files, especially CSV data.
In this scenario, The Fender, a fictional hacker, has compromised sensitive passwords. The goal of this project is to simulate a counter-hacking task by accessing, modifying, and securing the compromised data using Python.

-Objectives-
Access and read data from files
Work with .csv files using Python
Modify and rewrite sensitive information
Obscure (scramble) data for security purposes
Generate new files with updated content
Add a custom “signature” to the system

-What I Learned-
Reading and writing files in Python
Handling CSV files
Data manipulation and transformation
Automating file updates
Basic concepts of data security (obfuscation)
